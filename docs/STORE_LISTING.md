# Google Play 스토어 등록정보 초안

광고 없이 출시하는 첫 버전 기준입니다. 기능 설명은 앱 코드로 확인한 내용만 썼습니다. 기능이 바뀌면 이 문서도 함께 고치세요.

Play 글자 수 제한: 앱 이름 30자, 간단한 설명 80자, 자세한 설명 4,000자.

## 앱 이름

```
여행 준비 도우미: 경비·준비물·D-day
```

23자입니다. 이름만 쓰려면 `여행 준비 도우미`(9자)를 씁니다.

## 간단한 설명

추천 (47자):

```
떠나기 전 준비는 여기서. 경비 계산, 국가별 준비물, D-day 알림까지 한 번에.
```

다른 안:

```
여행 경비 계산부터 준비물 체크, 출발 D-day까지 한 번에 준비하세요.
```

```
예상 경비, 준비물, 출발일 D-day를 한 곳에서. 로그인 없이 바로 시작하는 여행 준비 앱
```

## 자세한 설명

약 980자입니다.

```
여행을 떠나기 전, 챙길 건 많고 돈 계산은 복잡하죠.
'여행 준비 도우미'는 예상 경비, 준비물, 출발일까지 여행 준비에 필요한 것을 한 곳에 정리해 주는 앱이에요. 회원가입이나 로그인 없이 바로 시작할 수 있어요.

■ 예상 경비를 한눈에
• 항공권, 숙박비, 식비, 교통비 등 항목별로 경비를 적어 보세요. 같은 항목도 여러 줄로 나눠 한 번에 저장할 수 있어요.
• 경비마다 원화나 현지 통화를 고를 수 있고, 참고 환율로 원화 금액을 자동으로 계산해요. 환율을 직접 입력할 수도 있어요.
• 예산 대비 사용 비율, 남은 예산, 항목별 차트로 경비 계획을 한눈에 확인하세요.

■ 빠짐없는 준비물 체크리스트
• 해외여행인지 국내여행인지에 맞춰 여권, 충전기, 상비약 같은 기본 준비물을 미리 채워 드려요.
• 항목을 추가하고 고치고 체크하면 바로 저장돼요.
• 유심과 eSIM은 여행 기간에 맞는 상품을 네이버 쇼핑에서 바로 찾아볼 수 있어요.

■ 설레는 출발일 D-day
• 여행 기간을 정하면 출발까지 남은 날을 홈 화면에서 보여 줘요.
• 알림창에 D-day와 남은 준비물 개수를 띄워 두고 매일 확인할 수 있어요. 표시할 내용과 이모지도 원하는 대로 바꿀 수 있어요.

■ 여행지 정보
• 28개 국가·지역을 지원해요.
• 일본, 미국, 태국, 베트남은 입국 준비에 도움이 되는 공식 안내 링크를 모아 두었고, 그 밖의 나라는 공통 여행 팁을 알려 드려요.

■ 내 정보는 내 휴대폰에만
• 입력한 여행과 경비는 휴대폰 안에만 저장되고, 운영자 서버로 보내지 않아요.
• 다크 모드와 큰 글씨에서도 편하게 쓸 수 있어요.

[알아 두세요]
• 환율은 참고용이며, 실제 결제 환율이나 수수료와 다를 수 있어요.
• 비자와 입국 조건은 출발 전 각 나라의 공식 안내를 꼭 확인하세요.
• 지금은 백업 기능이 없어서, 앱을 지우거나 휴대폰을 바꾸면 저장한 여행 정보가 사라져요.
• 연결되는 판매처는 앱과 별개인 업체이며, 제휴나 수수료가 없어요.
```

## 함께 올릴 것

- **앱 아이콘 (512×512):** `branding/play_store_icon_512.png`
- **스크린샷:** 첫 2~3장이 가장 많이 보입니다. 아래 순서를 추천합니다. 각 장 위에 짧은 문구를 얹으면 더 좋습니다.
  1. 예산과 차트가 보이는 여행 상세 화면: "예상 경비를 한눈에"
  2. 경비 입력 화면: "통화별 경비도 원화로 바로"
  3. 준비물 체크리스트: "빠짐없는 준비물 체크"
  4. D-day 알림: "설레는 출발까지 D-day"

## 쓸 때 주의할 점

- "최고", "1위", "무료 최강" 같은 과장 표현이나 다른 앱 이름은 Play 정책 위반으로 거절될 수 있습니다.
- "알아 두세요"는 환율 오차와 백업이 없다는 점을 미리 알려 낮은 별점 리뷰를 줄이려고 넣었습니다. 백업 기능이 생기면 해당 줄을 지우세요.
- 광고 기능을 켜면 "운영자 서버로 보내지 않아요"와 "제휴나 수수료가 없어요"를 고쳐야 합니다. `docs/PRIVACY.md`의 "광고 기능을 켤 때 추가할 내용"도 함께 반영하세요.
