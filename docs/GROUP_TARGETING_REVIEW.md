# 광고그룹 타겟 변경 시 재검수

그룹의 유심 종류, 국가 또는 사용 일수를 변경하면 연결된 소재에 새 설정을
반영하고 기존 승인 소재는 노출을 중지한 뒤 재검수한다.

서버에서 그룹 설정 변경과 같은 트랜잭션 안에 다음을 처리한다.

1. 해당 그룹의 삭제되지 않은 소재를 잠그고 변경된 설정을 반영한다.
2. 기존 승인 소재는 검수 대기로 전환하고 공개 광고를 중지한다.
3. 대기 소재는 대기 상태를, 반려 소재는 반려 상태와 사유를 유지한다.
4. 그룹 이름이나 입찰가만 바뀐 경우에는 소재의 노출 상태를 변경하지 않는다.
5. 변경과 검수 중에 같은 소재의 잠금을 사용해 승인 직후 변경된 경우에도 재검수한다.

실제 동시 요청과 여러 소재에 대한 추가 검증은 정식 운영 전에 필요하다.
