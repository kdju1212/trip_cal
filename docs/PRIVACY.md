# 개인정보처리방침 초안 — 출시 전 확정 필요

운영자명, 연락처, 시행일, 공개 URL: **출시 전 실제 정보로 확정**. 이 문서는 법률 검토를 대신하지 않습니다.

여행·경비·준비물·구매 필요 표시·설정은 기기 내부 SQLite에 저장합니다. 자체 서버, 로그인, AI API, 분석 SDK는 없습니다. Android 앱의 시스템 자동 백업은 꺼져 있습니다. 앱 삭제 시 로컬 데이터는 삭제됩니다. 앱 데이터의 내보내기/복원은 아직 제공하지 않습니다.

Frankfurter로 요청할 때 통화 쌍과 네트워크 정보가 해당 서비스에 전달됩니다. 여행 이름이나 전체 경비를 전송하지 않습니다. 참고 환율은 수수료와 실제 결제 시세를 보장하지 않습니다.

업체 광고 목록을 제공하도록 설정된 경우 여행 국가 코드, 통신 방식, 여행 일수와 네트워크 정보가 Supabase에 전달됩니다. 외부 상품 이미지 서버에도 네트워크 정보가 전달될 수 있습니다.

외부 판매처는 앱과 별도 사업자이며, 링크를 열면 각 사이트의 정책이 적용됩니다. 현재 링크에는 제휴 파라미터나 제휴 계약이 없습니다. 앱 내부 결제는 제공하지 않습니다.

문의, 권리 행사, 변경 공지, 아동 대상 여부 및 지역별 추가 요건은 운영자 결정과 정책 검토 후 확정합니다.
