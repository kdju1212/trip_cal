# 여행 준비 도우미 개인정보처리방침

> **초안 — 공개 전 확정 필요.** `[ ]`로 표시한 항목은 운영자가 실제 정보로 채워야 합니다. 이 문서는 법률 검토를 대신하지 않습니다.
> 이 방침은 **광고 없이 출시하는 첫 버전** 기준입니다. 광고 기능을 켜려면 이 문서 맨 아래의 "광고 기능을 켤 때 추가할 내용"을 본문에 반영한 뒤 공개해야 합니다.

[운영자명](이하 "운영자")은 「개인정보 보호법」 등 관련 법령을 지키며, '여행 준비 도우미' 앱(이하 "앱") 이용자의 정보를 다음과 같이 처리합니다.

- 시행일: [YYYY년 MM월 DD일]
- 공개 주소: [https://...]

## 1. 운영자가 수집하는 개인정보

**운영자는 이용자의 개인정보를 수집하거나 서버에 저장하지 않습니다.**

- 회원가입과 로그인이 없습니다.
- 이름, 연락처, 이메일, 위치, 연락처 목록, 사진 등을 요구하지 않습니다.
- 광고 SDK, 분석 SDK, 오류 수집 도구를 쓰지 않습니다.
- 앱 안에서 결제를 받지 않습니다.

## 2. 이용자 기기에만 저장되는 정보

앱에 입력한 정보는 이용자의 휴대폰 안에만 저장되고, 운영자에게 전송되지 않습니다.

| 저장하는 정보 | 쓰임 |
|---|---|
| 여행 이름, 여행 국가, 출발일·종료일, 예산 | 여행 목록, D-day, 남은 예산 표시 |
| 경비 항목, 금액, 통화, 환율 | 예상 경비 계산 |
| 준비물 목록과 체크 상태, 구매 필요 표시 | 준비물 체크리스트 |
| 화면 테마, D-day 알림 설정과 알림 문구 | 앱 설정 유지 |
| 최근에 받은 환율 | 인터넷이 없을 때 직전 환율 표시 |

- Android 자동 백업 기능을 꺼 두어, 이 정보가 Google 계정 백업으로 복사되지 않습니다.
- 앱을 삭제하면 위 정보도 모두 삭제됩니다. 앱 안에서 여행을 삭제하면 그 여행의 경비, 준비물, 구매 필요 표시도 함께 삭제됩니다.
- D-day 알림을 켜면 여행 이름, 남은 일수, 출발일(또는 직접 입력한 문구), 남은 준비물 개수가 알림 영역에 표시되며 잠금 화면에도 보일 수 있습니다. 앱의 알림 설정에서 표시할 항목을 고를 수 있고, 휴대폰의 알림 설정에서 잠금 화면 표시를 끌 수 있습니다.

## 3. 외부 서비스로 전달되는 정보

일부 기능은 이용자의 휴대폰이 외부 서비스에 직접 접속합니다. 이때 운영자는 정보를 받지 않으며, 각 서비스는 접속 과정에서 IP 주소 등 네트워크 정보를 처리할 수 있습니다.

| 서비스 | 언제 | 전달되는 정보 |
|---|---|---|
| Frankfurter (환율 정보, 해외 서비스) | 경비 입력에서 환율을 불러올 때 | 조회하는 통화 코드(예: JPY), 네트워크 정보 |
| 네이버 쇼핑 | 유심·eSIM 검색 링크를 누를 때 | 검색어(여행 국가, 유심/eSIM, 이용 일수), 네트워크 정보 |
| 각국 공식 안내 사이트, 판매처 홈페이지 | 앱에 표시된 링크를 누를 때 | 해당 사이트 접속 정보 |

- 여행 이름, 예산, 경비 내역 전체는 어느 외부 서비스에도 보내지 않습니다.
- 링크는 휴대폰의 브라우저나 해당 앱에서 열리며, 그때부터는 각 사이트의 개인정보처리방침이 적용됩니다.
- 링크에는 제휴 코드가 없고, 운영자는 링크를 통한 구매로 수수료를 받지 않습니다.
- 앱의 환율은 참고용이며, 실제 결제 환율과 수수료는 다를 수 있습니다.

## 4. 앱이 요청하는 권한

| 권한 | 쓰임 | 거부하면 |
|---|---|---|
| 인터넷 | 환율 조회, 외부 링크 열기 | 직접 입력한 환율로 계속 사용 가능 |
| 알림 (Android 13 이상) | D-day 알림 표시 | D-day 알림만 표시되지 않음 |
| 부팅 완료 후 실행 | 휴대폰을 다시 켠 뒤 D-day 알림 복원 | 별도 요청 없이 설치 시 허용됨 |

## 5. 개인정보의 제3자 제공, 처리 위탁, 국외 이전

운영자가 수집하는 개인정보가 없으므로, 제3자에게 제공하거나 처리를 위탁하거나 국외로 옮기는 개인정보도 없습니다. 3항의 외부 서비스는 이용자가 기능을 쓸 때 휴대폰이 직접 접속하는 것입니다. [법률 검토: Frankfurter 접속 시 네트워크 정보 처리를 국외 이전 고지 대상으로 볼지 확인]

## 6. 보유 기간과 파기

운영자가 보관하는 개인정보가 없습니다. 기기에 저장된 정보는 이용자가 앱에서 삭제하거나 앱을 삭제할 때 지워집니다.

## 7. 이용자의 권리

이용자는 앱 안에서 직접 여행과 경비, 준비물을 조회·수정·삭제할 수 있습니다. 운영자는 이용자의 정보를 갖고 있지 않으므로, 따로 열람이나 삭제를 요청하실 정보는 없습니다. 궁금한 점은 아래 문의처로 연락해 주세요.

## 8. 아동의 개인정보

앱은 개인정보를 수집하지 않으며, 만 14세 미만 아동을 대상으로 하지 않습니다. [Play 대상 연령 설정과 맞춰 확정]

## 9. 안전성 확보 조치

- 외부 통신은 암호화된 HTTPS로만 합니다.
- 기기 안의 정보는 Android가 이 앱에만 접근을 허용하는 저장 공간에 둡니다.
- 휴대폰 잠금을 설정하면 다른 사람이 앱 정보를 보는 것을 막는 데 도움이 됩니다.

## 광고 기능을 켤 때 추가할 내용 (공개 전 본문 반영, 이 제목 아래는 공개하지 않음)

광고 기능(유심·eSIM 판매처 광고)을 켜면 앱이 운영자의 서버(Supabase)에 접속하므로, 1항의 "수집하지 않습니다"가 더 이상 사실이 아닙니다. 아래 내용을 1·3·5·6항에 반영해야 합니다.

- **보내는 정보:** 광고 목록을 볼 때 여행 국가 코드, 유심/eSIM 구분, 여행 일수를 보냅니다. 광고를 누르면 광고 번호와 앱 설치 시 기기에 만든 무작위 식별자를 보냅니다.
- **서버에 기록되는 정보:** 광고 번호, 노출·클릭 구분, 시각을 기록합니다. 반복·자동 클릭을 가려내기 위해 설치 식별자는 날짜별로 바뀌는 값으로 변환해 최대 24시간 보관합니다. IP 주소는 저장하지 않고, 매일 새로 만들고 다음 날 지우는 비밀 값과 함께 일방향 변환(해시)한 값만 노출 제한에 최대 10분, 클릭 분석에 최대 24시간 보관합니다.
- **처리 위탁·국외 이전:** Supabase(서버 위치 [리전 확인])를 처리 위탁 및 국외 이전 항목에 적어야 합니다.
- **광고 이미지:** 광고 이미지를 불러올 때 이미지 서버가 네트워크 정보를 처리합니다.
- **보유 기간:** 광고 노출·클릭 기록의 보유 기간과 파기 방식을 정해야 합니다. [미정]
